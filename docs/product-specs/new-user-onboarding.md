# 新用户引导

新用户通过官网注册或登录。账号未验证时，工作台提示先通过邮箱完成验证。登录后从工作台创建项目，输入提示词或选择参考素材。已建立项目可以在最近项目和项目列表中再次打开。

| 场景 | 可观察的结果 |
| --- | --- |
| 登录成功 | 进入工作台，或返回登录前选择的个人中心 |
| 登录失败或邮箱未验证 | 展示对应错误或验证提示，可以继续登录或恢复密码 |
| 第一次打开工作台 | 可以创建空项目，也可以提交提示词后进入画布 |
| 第一次进入个人中心 | 可以查看当前订阅状态和本月额度 |

规则细节以 [PRD · 使用权限](../prd.md#使用权限) 与 [PRD · 创作首页](../prd.md#创作首页-protected) 为准。
