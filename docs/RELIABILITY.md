# 可靠性

| 流程 | 需要核对的条件 |
| --- | --- |
| 生图 | 已提交任务可按状态查看。失败重试复用原参数，额度按业务规则计算。 |
| Qwen 排版 | 确认的快照和样式随任务保存。检查刷新恢复、失败提示、重试，以及并发提交是否产生重复模型调用。 |
| 稿件保存 | 使用稿件版本处理冲突。用户修改后重新生成时保留旧稿。 |
| 发布图片 | 所需副本全部可访问后再复制。检查公开地址稳定，图片失败时可重试。 |
| 支付 | 通过服务端验签、金额校验和事务入账确认。测试重复通知和并发续订。 |

排查时先确认受影响的项目和任务状态，再查对应服务日志。记录任务 ID、状态码和复现步骤，业务载荷、签名和密钥留在其受控环境中。已知改进项见 [技术债](./exec-plans/tech-debt-tracker.md)。
