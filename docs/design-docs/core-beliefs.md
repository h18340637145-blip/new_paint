# 核心原则

- **入口短，细节可定位。** 用 AGENTS.md 说明从哪里开始。产品规则查 PRD，数据约束查迁移，跨模块设计查架构和设计文档。
- **验收有证据。** 记录验证命令、环境和用户能观察到的结果。外部服务需要实际响应或浏览器操作证据。
- **用户意图与外部结果分开。** 保存连线、原文、人工编辑和所选模板。模型输出经校验才进入正文，支付以已验签的异步入账为准。
- **把保护措施放在数据边界。** 用登录态和归属校验保护接口，用 RLS 和约束保护数据库，用版本与状态处理并发和重试。
- **随变更维护资料。** 更新受影响的产品规则、架构约束和验收记录。重复的信息保留一个权威入口，其余用相对链接引用。
