# 安全

- 客户端只使用 `NEXT_PUBLIC_` 中允许公开的配置。Supabase 管理凭据、模型密钥、数据库连接串和 ZPAY 签名密钥仅从服务端环境或 Vault 读取。
- 写入或导出项目前，以当前用户会话校验项目和资源归属。鉴权、服务端校验和 RLS 同时覆盖项目、稿件、素材及付款记录。
- 素材原件保存在 `project-images` 私有桶。用户确认公开后，仅复制该稿件导出所需的图片到 `published-article-images`，链接可被持有者读取。
- 用户输入和模型结果进入预览或导出前先校验，文本转义、URL 限制、样式与组件的允许范围在渲染边界检查。验证富文本时要覆盖脚本、事件属性和危险链接。
- ZPAY 仅凭符合签名和订单数据的异步通知入账，验证签名、商户、金额、付款方式及重复通知。日志避免记录凭据和完整支付签名。

权限与对象定义从 [数据库结构索引](./generated/db-schema.md) 追溯到迁移。
