# 公众号文章封面

1. 读取用户上传的 Markdown 全文。用一句话概括主题，提炼一个短标题，保留文章中的实体名和关键事实。缺少全文时请用户补交附件。
2. 先询问用户选择「极简大字报 / 杂志封面 / 插画 / 科技 / 孟菲斯」，给出主题和短标题。等待用户选择。
3. 收到选择后，在同一轮调用现有 `generate_image` 工具，提供四条不同的构图提示词，使用同一个短标题、统一色系和同一种风格。使用 16:9 宽幅，关键文字和主体置于画面中央安全区，预留裁切空间。出现参考图时，先调用 `view_image`，再按用户指定顺序传入资产编号。
4. 四张封面分别采用左文右图、右文左图、居中上下布局、对角平衡布局。标题必须使用用户语言且拼写准确。画面保留明确的视觉层级，避免添加标识、水印或额外文案。

| 风格 | 配色与画面 | 字体 |
| --- | --- | --- |
| 极简大字报 | 高对比双色与大面积留白，可用一枚简单几何形 | 粗黑无衬线，短标题加大 |
| 杂志封面 | 米白、深灰与一处点缀色，使用编辑式网格与主体照片感 | 有辨识度的标题衬线体，字距适中 |
| 插画 | 低饱和的协调色，主体插画承担文章的核心隐喻 | 易读的圆润无衬线，控制描边 |
| 科技 | 深蓝或黑底，青紫冷色强调，细线与网格作辅助 | 清晰的几何无衬线，可用等宽数字 |
| 孟菲斯 | 高饱和撞色，少量波点、折线和几何色块 | 厚重无衬线，标题与背景有明显对比 |
