# 画布文章复制到公众号验收

状态为待外部验收。画布编排、Qwen 生成、稿件编辑和发布图片路径已存在于仓库。实施记录见 [已完成](../completed/index.md)，当前效果以以下实测为准。

- 在 Chrome 使用有权访问测试项目的账号创建文章主链，至少包括一段创作素材、一段原文保留、一张上传图和一张生成图。
- 暂存后确认模板与版本，运行 Qwen。核对原文保留、图片顺序和人工修改的选区样式。刷新后重新打开稿件，确认修改仍在。
- 确认图片公开并复制。用匿名请求读取两张发布图，确认 URL 可访问，重复导出相同素材时地址稳定。测试素材使用可公开的图片。
- 在有权编辑的微信公众号后台粘贴富文本，保存为草稿，关闭后重新打开。记录标题层级、字号、选区颜色、列表和图片保留情况。需要验证正式发布时，使用明确授权的测试文章。

记录浏览器版本、验证环境、测试时间、实际结果和未通过项。接入边界见 [画布文章工作流](../../design-docs/canvas-article-workflow.md)。
