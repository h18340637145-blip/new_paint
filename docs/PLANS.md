# 执行计划

涉及多个模块、数据库迁移或外部服务的工作，在 `docs/exec-plans/active/` 中记录目标、已确认规则、实现顺序和验收。单个文案或样式变更可以在提交说明中描述。

1. 建计划时记录状态、现有入口、依赖、变更范围和可观察的验收项。每条开放问题说明它会影响哪个决策。
2. 实施中更新计划的已完成、待办与阻塞项。记录实际运行的命令、环境和外部验收结果。
3. 当该计划的目标达成后，移入 `completed/`，在索引中添加链接。后续需要改进的事项记入技术债，补充验证或收尾工作可另开计划。

计划以 [进行中](./exec-plans/active/index.md)、[已完成](./exec-plans/completed/index.md) 和 [技术债](./exec-plans/tech-debt-tracker.md) 为入口。产品规则更新到 [PRD](./prd.md)。
